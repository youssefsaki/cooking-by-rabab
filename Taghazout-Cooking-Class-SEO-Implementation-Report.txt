================================================================================
TECHNICAL FIXES — CONSOLE & HYDRATION ERRORS
================================================================================

ISSUES IDENTIFIED
  1. Hero alt hydration mismatch (server vs. client alt text)
  2. ThingsToDoSection dynamic import crash (webpack chunk error)
  3. Stale browser cache serving old JavaScript bundles after dev rebuilds

FIXES APPLIED
  1. components/Hero.tsx
     Alt text now sourced from heroData.backgroundImage.alt (data/hero.json)
     ensuring identical values on server and client renders.

  2. app/page.tsx
     ThingsToDoSection changed from dynamic() import to static import,
     eliminating lazy-load chunk failures.

  3. components/ThingsToDoSection.tsx
     Fallback added: t.thingsToDo ?? en.thingsToDo for translation safety.

  4. Dev environment
     .next cache cleared; production build verified clean.

RECOMMENDED FOR LIVE TESTING
  Hard refresh (Cmd+Shift+R) or incognito window after deploy to avoid
  stale cached JavaScript bundles in the browser.
